## Hotel Booking Data Analysis

An end-to-end data analysis project using Microsoft SQL Server and Power BI to analyse hotel booking data and provide insights for stakeholders.

## Project Overview

The project focuses on analysing hotel booking data to understand revenue growth, booking trends, seasonal patterns, and parking requirements.

## Business Questions

* Is hotel revenue growing year by year?
* Should the hotel increase the size of its parking facilities?
* What trends and seasonal patterns can be identified from the average daily rate and guest numbers?

## Data Analysis

The project includes database development and SQL analysis to prepare and analyse the hotel booking data. SQL queries were used to examine revenue, booking trends, hotel performance, and parking requirements.

## Power BI Dashboard

The dashboard provides insights into hotel revenue, average daily rate, total nights, discount levels, parking requirements, and revenue performance across different hotel types and years.
